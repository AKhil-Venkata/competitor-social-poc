Privacy Policy

Social Media Competitor POC · Effective date: 23 November 2026

This Privacy Policy explains how the Social Media Competitor POC (the “Application”) handles information when operated by its developer for internal testing and analytics.

Project status: This is an internal proof of concept, not a public consumer service. The Application is intended to use only information made available through relevant platform APIs and permissions. Data availability depends on platform approval, API rules and account eligibility.

1. Information the Application may process

Depending on the platform, API product, permissions and successful access, the Application may process:

  • Public account or Page identifiers, names and usernames;
  • Public post or video identifiers, captions or descriptions, publication dates and permalinks;
  • Engagement metrics made available by the platform API, such as likes, reactions, comments, shares or video views;
  • API response metadata, technical logs and error information;
  • Access tokens and application credentials required for API requests.

The Application does not intentionally seek private messages, passwords, private account content or restricted personal information. It does not claim access to metrics that the relevant API does not provide.

2. How information is used

Information available to the Application is used for internal proof-of-concept testing, social media content analysis, aggregate engagement measurement, publishing-frequency analysis and comparison of publicly available content across selected banking brands.

3. Data sources and platform APIs

The Application may connect to Meta (Facebook and Instagram) and TikTok developer APIs. Each platform controls its own API, permissions, data availability and retention requirements. Use of platform data is subject to applicable platform terms and developer policies. The Application will only make API requests within the access actually granted to it.

4. Storage and security

The current proof of concept is designed to run locally on a developer-controlled computer. Data exports may be stored in local CSV or JSON files. API credentials and access tokens should be stored in local environment configuration and must not be published in source control or shared in screenshots or messages.

No absolute security guarantee can be made. The developer takes reasonable steps appropriate to this prototype to restrict access to local files and protect credentials.

5. Sharing and service providers

The Application is not designed to sell personal information or provide platform data to data brokers. Data is not intentionally shared with external processors as part of the current local prototype. If hosting, cloud storage, analytics services or other processors are added, this policy must be updated before those services receive data.

6. Retention and deletion

Information is retained only for as long as needed for the internal prototype, testing and analysis, subject to applicable platform requirements. Local data files and credentials can be deleted by the developer. Requests concerning platform data should also be handled in accordance with the relevant platform’s developer policies and deletion requirements.

7. Your choices and requests

For privacy questions or requests relating to this Application, contact the developer using the contact details below. Please do not send passwords, access tokens or other secrets in a request.

8. Children

This internal analytics prototype is not directed to children and is not intended for use by children.

9. Changes to this policy

This policy may be updated as the prototype, its data sources or its processing practices change. The effective date above will be revised when an update is published.
